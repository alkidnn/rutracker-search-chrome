## ✨ Возможности

- **Контекстное меню** — выделите текст → правая кнопка мыши → *"Найти на Rutracker"*
- **Popup-окно** — введите запрос или используйте автоматически подставленный выделенный текст
- **Горячая клавиша** — `Ctrl+Shift+R` для мгновенного поиска выделенного текста
- **Минималистичный дизайн** — ничего лишнего, только поиск
- **Поддержка Manifest V3** — современное расширение для Chrome/Edge/Brave

---

## Установка (без Chrome Web Store)
1. Скачайте архив с кодом (зелёная кнопка `Code` → `Download ZIP`).
2. Распакуйте его в отдельную папку.
3. Откройте в браузере `chrome://extensions`.
4. Включите **«Режим разработчика»** (в правом верхнем углу).
5. Нажмите **«Загрузить распакованное расширение»** и выберите папку.
6. Готово! Иконка появится в панели браузера.
